# My Web Development Project - Travel Website

This is a multi-page website project I built to practice my front-end web design and coding skills. I decided to make a travel and tourism site, including a page focused on trekking in the Annapurna region of Nepal. 

## 🚀 See It Live!
You can view my live website here: https://github.io

## 🛠️ Languages and Tools I Used
* **HTML5:** I used this to build the structure, text layout, and links for all the pages.
* **CSS3:** I used this to design the colors, spacing, and grids to ensure the pages look clean.
* **Media Queries:** I added these to make sure the pages automatically adjust and look good on mobile screens, tablets, and computers.
* **Git & GitHub:** I used this for tracking my code changes, creating branches for separate tasks, and deploying the live site using GitHub Pages.

## 📈 What's Inside This Project
* **Annapurna Trek Page:** A custom page layout that organizes text and images highlighting local travel details.
* **Responsive Layouts:** Code structures that adapt smoothly across different device sizes.
* **Organized Folders:** I separated my files neatly so that all my style sheets are in a `/css` folder and my photos are in an `/images` folder.
